# Arthur Blog

Personal blog built with Next.js. A modern, performant blog platform with server-side rendering and static site generation capabilities.

[🚀 Live Demo](https://arthur-blog.ug02fast.vercel.app)

## Features

- **Next.js Framework**: Server-side rendering and static generation
- **Markdown Support**: Write blog posts in Markdown
- **Fast Performance**: Optimized for speed and SEO
- **Modern Stack**: Built with React and Next.js

## Tech Stack

- **Framework**: Next.js
- **Language**: JavaScript
- **UI**: React

## Installation

```bash
git clone https://github.com/arthur-zhuk/arthur-blog.git
cd arthur-blog
npm install
```

## Usage

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the blog.

## Development

```bash
npm run dev    # Start development server
npm run build  # Build for production
npm start      # Start production server
```
